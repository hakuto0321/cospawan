# スマホで確かめる方法

目的：PC から離れていても、画面の見た目と動きを確かめられるようにする。

---

## 1. 開発サーバーを同じ Wi-Fi のスマホから開く

PC が起きていて、サーバーが動いている間だけ使えます。

1. PC のターミナルで、次を実行します（仮データで動きます）。

   ```bash
   cd /Users/hasegawakouichi/workspace/cospawan && DATA_SOURCE=mock npx next dev -H 0.0.0.0 -p 3000
   ```

2. 別のターミナルで、PC の IP アドレスを確かめます。

   ```bash
   ipconfig getifaddr en0
   ```

3. スマホのブラウザで `http://（表示された IP）:3000` を開きます。

注意：
- 仮データの間は、商品名も価格も架空です（画面に「開発中」と出ます）。
- PC がスリープすると、スマホからは見られません（Claude の作業中は起きていますが、ふたを閉じると止まります）。

## 2. Claude の画面（スマホの Claude アプリ・claude.ai）から見る

- **タスク表（WBS）**：Artifact のページ。どの端末でも、同じ状態が見えます。
- **このセッション**：Remote Control をオンにすると、スマホからこのセッションを見られます。

## 3. 公開したあと（Cloudflare）

- workers.dev の URL（公開後に決める）を、スマホのブラウザで開きます。
- 確かめる場所：トップ（犬・猫の切り替え、ピックアップ、おトク順、口コミ順）、商品ページ（冒頭の一文、ショップ比較、送客ボタン）、事前登録フォーム。
- 実際の価格が出ているかは、「取得した日時」の表示で確かめます。

## 4. 見るときのチェック（短く）

- [ ] 文字が切れていない・横にはみ出していない
- [ ] 数字（価格）が正しい桁で出ている
- [ ] 「取得した日時」が新しい
- [ ] 送客ボタンが押せて、ショップが開く
- [ ] 「開発中」「仮データ」の表示が、本番では出ていない
