## A. オーナー側の準備（審査や発行に時間がかかるので、早めに並行して進める）

- [ ] 👤 A1. ドメインを決める・取る（楽天の「登録サイトURL」やアフィリエイト申請で必要）
- [ ] 👤 A2. Cloudflare アカウントを作り、ドメインをつなぐ
- [ ] 👤 A3. Supabase で開発用プロジェクトを作る（本番用は公開直前でよい）
- [ ] 👤 A4. 楽天ウェブサービス：アプリID・アクセスキーを発行、サイトURLを登録
- [ ] 👤 A5. 楽天アフィリエイト：アフィリエイトIDを取る
- [ ] 👤 A6. Yahoo! デベロッパー：Client ID を発行
- [ ] 👤 A7. バリューコマース（Yahoo!ショッピングのアフィリエイト）に申請
- [ ] 👤 A8. Amazon アソシエイトに申請（審査あり。サイト公開後でないと通りにくい）
- [ ] 👤 A9. 問い合わせ先のメールアドレスを決める

キーやIDは `.env.local` に入れる（コミットしない）。チャットには貼らなくてよい。

- [x] 🤖 B1. Next.js（App Router + TypeScript）の雛形

- [x] 🤖 B3. DBのテーブル定義（SQLマイグレーション）
- [x] 🤖 B4. 実質価格の計算と、おかしな値を保留にする判定（テスト付き）
- [x] 🤖 B5. 仮データで画面を作る：トップ「今日の買い時」（犬・猫の切り替え）
- [x] 🤖 B6. 仮データで画面を作る：商品ページ（冒頭の一文、ショップ比較、Q&A、構造化データ）
- [ ] 🤖 B7. 固定ページ：プライバシーポリシー、利用規約、問い合わせ先
